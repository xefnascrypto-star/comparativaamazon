ANTES DE EMPEZAR

El modelo importa

  1. Identifica el aparato y la marca.
    Un mismo código puede tener significados distintos.
  2. Anota el código completo.
    Incluye letras y números tal como aparecen.
  3. Contrasta con tu manual.
    Las guías del prototipo están pendientes de revisión por modelo.
