El ventilador funciona pero el horno no calienta

El ventilador puede funcionar aunque el sistema de calentamiento no esté actuando. Antes de pensar en una resistencia averiada, revisa la configuración.

Comprobaciones seguras

  1. Confirma que no esté seleccionado solo ventilación o descongelación.
  2. Selecciona una temperatura claramente superior a la ambiente.
  3. Comprueba el reloj/temporizador si el modelo exige tenerlo configurado.
  4. Prueba otro modo de cocción siguiendo el manual.
  5. Si hubo un corte de corriente, revisa si necesita reprogramación.

Si ningún modo genera calor, la resistencia, el control de temperatura o la electrónica pueden necesitar diagnóstico.

Las resistencias y conexiones trabajan con tensión de red. No retires paneles ni hagas mediciones internas sin cualificación.

Relacionado: horno no calienta.
