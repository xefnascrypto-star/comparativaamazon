El frigorífico no congela bien

Antes de pensar en una avería grave

  1. Comprueba el ajuste de temperatura.
  2. Verifica que la puerta cierre y la junta selle correctamente.
  3. No bloquees las salidas de aire con alimentos.
  4. Deja espacio exterior suficiente para ventilación.
  5. Comprueba si existe una acumulación anormal de hielo.
  6. Tras cargar muchos alimentos, espera el tiempo necesario para recuperar temperatura.
Si el compresor funciona continuamente, el aparato no recupera temperatura o sospechas una fuga de refrigerante, requiere técnico. No manipules el circuito frigorífico.

Relacionado: frigorífico no enfría.
