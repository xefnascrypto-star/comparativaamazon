El congelador funciona pero el frigorífico no enfría

Este síntoma suele orientar hacia un problema de circulación del aire frío entre zonas, aunque el diseño cambia según el modelo.

Seguridad: no desmontes ventiladores, resistencias de desescarche ni paneles eléctricos. Las comprobaciones deben limitarse a elementos visibles y accesibles.

Causas que conviene descartar

Rejillas interiores bloqueadas
No pegues alimentos a las salidas de aire. Deja espacio para que el aire circule.
Exceso de hielo
Una acumulación anormal puede bloquear conductos. Sigue el procedimiento de descongelación indicado por el fabricante.
Puerta o junta
Una entrada continua de aire húmedo puede favorecer hielo y empeorar la temperatura.
Ventilación interna
Si el modelo utiliza ventilador y no se percibe circulación de aire, puede existir una avería que requiera diagnóstico profesional.

Si el problema continúa

Un sensor, ventilador, sistema de desescarche o compuerta de aire pueden estar implicados. Si tras las revisiones básicas la zona de refrigeración sigue caliente, solicita asistencia técnica.
